One PaySME payment journey.

This page maps how a merchant’s client moves from an app, website, invoice, subscription, QR code or payment link into the common PaySME payment modal—then completes immediately or returns later through the SMS payment link.

Core business rules

  • Every route ultimately reaches the PaySME payment modal.
  • Every initiated transaction sends an SMS containing a payment link.
  • Request to Pay and Bulk Invoicing pre-generate and send the PayCode.
  • Failed payment status is visible immediately on the UI.
  • Success triggers a client confirmation SMS and merchant notification.

Control points and implementation implications

These rules apply consistently across merchant onboarding, UI design and facilitator integration.

1. One common modalMerchants choose the starting channel, while PaySME standardizes the downstream checkout and status experience.
2. SMS re-entryThe SMS payment link reduces abandonment by allowing the client to return after the original session ends.
3. Immediate failure visibilityThe payment modal must display failed status immediately so that the client is not left uncertain.
4. Dual success notificationThe client receives a success SMS, and the merchant receives a successful-payment notification.
